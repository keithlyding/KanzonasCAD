# Bug reports and suggestions

Thanks for using KanzonasCAD! Bug reports and ideas are always welcome: please open an issue
with the **Bug report** or **Feature request** form, and include a drawing or screenshot if you
can.

**Never attach a client's real drawing**: make a sample that shows the problem.

For anything that could let a file run code or expose data, follow [SECURITY.md](SECURITY.md)
instead of opening a public issue.
