# Changelog

Each revision gets a version number, shown in the window title bar's About box (Help > About
KanzonasCAD).

| Version | Commit | Changes |
| --- | --- | --- |
| 0.1 | (this) | First version: the foundation. Projects of ANSI sheets (A-D, inches) with a border, a grid of zones (columns 1, 2, 3 across, rows A, B, C down) and a title block filled from the project's fields; page numbers by position or typed per sheet; grid references in a set format (6-D1). Drawing like AutoCAD: command line with names and aliases (LINE/L, PLINE/PL, RECTANG/REC, CIRCLE/C, ARC/A, TEXT/T, MOVE/M, COPY/CO, ROTATE/RO, SCALE/SC, MIRROR/MI, ERASE/E, TRIM/TR, ZOOM/Z, U, REDO), typed points (x,y  @dx,dy  @d<a, direct distance), Enter repeats; object snaps (end, mid, center, quadrant, intersection, insertion) with markers, ortho (F8), grid snap (F9), grid display (F7), osnap (F3); crosshair and pickbox; window (left to right) and crossing (right to left) selection, Shift+click to remove; grips to stretch; Trim in quick mode; clipboard between projects (handed over to the system as plain text when the app closes: Qt for Python crashes at exit while the clipboard holds data made in Python); layers (color, on/off, lock, current layer, move selection to a layer); undo/redo of everything through before/after records (model.Edit). Files: .kzcad projects (JSON, saved atomically), DXF import (inches or millimeters; blocks and dimensions exploded) and export (AutoCAD 2013, one sheet per file, frame on layer BORDER), PDF export (vector, real page sizes). Look shared with KanzonasPDF: menus, the ribbon (Home, Sheets, Output, View), light/dark theme, Material Design icons. Spatial index per sheet and chunked path cache: a 60,000-line sheet opens and draws in about 0.6 s. Self-test and unit tests; Windows and Linux builds. |
