# Changelog

Each revision gets a version number, shown in the window title bar's About box (Help > About
KanzonasCAD).

| Version | Commit | Changes |
| --- | --- | --- |
| 0.4 | (this) | Device tags by page number (tags.py): a placed symbol whose role is device or parent and whose symbol has a prefix gets prefix + page + two-digit count (CR601, M601; page 12: CR1201), the lowest free per prefix and page, and a hidden id (attribute DEV) that survives renaming. Copies (Copy, Paste, Mirror keeping originals, Ctrl+drag) get their own tag and id, taking the page they land on. Tags follow page numbers when a sheet is renumbered or moved (sync_pages at the end of every edit that touched sheets). A tag typed by hand locks itself (TAG_LOCK; Lock this tag in the attributes box). Renumber sheet (Schematic tab, Sheets menu) numbers unlocked devices per prefix in the sheet's numbering order (Sheet properties: across then down, or down then across), skipping locked numbers. Fixed: Mirror keeping originals replaced a mirrored object's original instead of adding the copy. docs/ROADMAP.md takes in the owner's brief (panel sheets with one scale and paper-height text, part assignment, library management, device-based links, DWG import with ezdwg). |
| 0.3.3 | (this) | Fixed: with Windows in dark mode, Qt darkened the window by itself while the theme was Light, and the dark gray tool icons vanished. The Light theme now uses a light palette of its own (not the style's), Qt is told the chosen scheme (QStyleHints.setColorScheme, Qt 6.8+), icons take the palette's text color, and Same as system follows the system switching while open. |
| 0.3.2 | (this) | Updates through the app, as in KanzonasPDF (updates.py): a daily background check of GitHub's releases (Check for updates automatically; Check for updates... in Help), a box with the notes of every version since yours (from the release text between kanzonascad-notes marks) and Update now / Skip this version / Later. From source: git checkout main, git pull --ff-only, pip install, then restart. The Windows build: the release zip downloaded, used only when its sha256 matches GitHub's digest, unpacked beside the program, swapped in by a script once KanzonasCAD closes, restarted. Linux build: opens the release page. Releases: job publish makes a full release v<version> for each new version on main (both downloads, notes); Qt's network module kept in the build. |
| 0.3.1 | (this) | The Library is a popup window (as AutoCAD Electrical's icon menu) instead of a panel on the right, so the drawing keeps the whole width: Insert symbol... (Schematic tab) opens it on Symbols, Insert footprint... (Panel tab) on Footprints, Library... (Library menu) as left; it hides while a block is placed and reopens where it was last put. Circle's other ways, as AutoCAD's: Center, diameter; 2-Point; 3-Point; Tan, tan, radius (lines, polyline segments, circles, arcs; geometry.tangent_circles picks the fit nearest the picks); CIRCLE's 3P/2P/TTR options; a ribbon split button showing the way used last (ribbon.SplitButton in large groups). Bus (BUS/BU): 2-50 wires at a spacing, drawn along a clicked path turning 90 degrees at each click, all wires turning together with the spacing kept (commands.bus_paths); remembers count and spacing; F puts the wires on the other side. One-pixel lines drawn without smoothing on screen, as AutoCAD does (a smoothed line between pixel rows showed at half strength). |
| 0.3 | (this) | Wires. Wire (WIRE/W): click to click, straight across and up or down with one corner per click (follows the cursor; F flips it; U takes back a click); ends by itself on a pin or another wire, Enter or Esc or another command keeps what is drawn (Polyline too now, as AutoCAD's PLINE). model.Wire (a polyline on layer WIRES). Connections worked out from the drawing, never stored (wires.py): junction dots where a wire ends on another's middle or three ends meet, drawn per sheet version. Moving a symbol drags the wire ends on its pins, kept square with a corner slid or a jog added (Edit.pin_moves, wires.follow_pins at the end of every edit; wires moved in the same edit are left alone). Placing a symbol on a wire cuts the wire between its pins (wires.break_under). |
| 0.2 | (this) | Symbols, footprints and parts. A library folder of your own (Documents/KanzonasCAD Library to start, Library folder... to change; library.py) kept apart from the program and projects: schematic symbols (blocks with pins and a tag position, role device/parent/child, contact type, tag prefix), panel footprints (real-size outlines) and a parts catalog (manufacturer, catalog number, description, linking a symbol and a footprint). 27 built-in JIC/NFPA symbols drawn from code (symbols_jic.py), pins on the 1/8 inch snap; yours of the same name replace them. Library panel (search, Symbols/Footprints/Parts, previews, Insert, New part..., Delete). Make block (BLOCK/B): base point, details, pins in order, tag position; saved to the library and optionally replaces the selection. Insert (R turns 90, F flips), Explode (X). Block references (model.Insert) carry TAG/DESC/MFR/CAT/PART attributes, edited by double-clicking (pick one of the library's parts for it); the project keeps its own copy of each block (Project.blocks, undoable), so it opens the same anywhere; copy/paste carries the definitions between projects; DXF export writes them exploded. Scale has Reference (pick a known length, type the real one) and lengths can be typed in millimeters (45mm) anywhere. Text justification as AutoCAD's (Text.valign: baseline, bottom, middle, top, with left/center/right; TEXT's Justify option TL...BR, L, C, R; kept through DXF export and import), and double-clicking a text opens Edit text: wording, height, angle and justification, optionally keeping the text in place. Zones: 8 rows (A-H) to start; columns and rows editable with the first column number and first row letter (Sheet.col_start, row_start); grid references follow them. Project and sheet settings split as in AutoCAD Electrical: Project properties has General (title block fields, revision, grid reference format, text height), Schematic (default size and zones, device tag height, wire and symbol colors) and Panel (footprint and dimension colors) tabs; Project.settings holds the defaults, sheets follow them unless they have their own (Sheet.own_layout; Edit.project_settings updates following sheets and tag heights in one undoable step); Sheet properties has title, page number, its own revision (sheet fields override project fields in the title block) and own size/zones. Ribbon Schematic and Panel tabs, always available. Objects are ByLayer unless given their own color (Modify > Color...); layers PANEL and DIMENSIONS added. Sheet type (Sheet.kind: schematic, panel, report, other) as a label: shown in the Sheets panel, brings up the matching ribbon tab, copied to new sheets. Backups (backup.py): each Save first copies the previous file into "<name> backups" beside it, newest 10 kept (File > Open backups folder); autosave every 5 minutes of projects with unsaved changes into a recovery folder, removed on save or normal close, offered back at the next start after a crash. |
| 0.1 | (this) | First version: the foundation. Projects of ANSI sheets (A-D, inches) with a border, a grid of zones (column numbers along the top, row letters down the left only) and a title block: the project's own small drawing (Project.title_block, a sheet with id 0, edited with Sheets > Edit title block like any drawing, DXF import included), drawn in the lower right corner of every sheet with {Field} texts filled in (project fields, {Sheet}, {Sheets}, {Sheet title}, and fields of your own, which Project properties then lists); double-clicking the title block opens Project properties. Black drawing background by default (View > Black drawing background, kept in the settings, independent of the menus' theme); PDF export always prints every object black on white; page numbers by position or typed per sheet; grid references in a set format (6-D1). Drawing like AutoCAD: command line with names and aliases (LINE/L, PLINE/PL, RECTANG/REC, CIRCLE/C, ARC/A, TEXT/T, MOVE/M, COPY/CO, ROTATE/RO, SCALE/SC, MIRROR/MI, ERASE/E, TRIM/TR, ZOOM/Z, U, REDO), typed points (x,y  @dx,dy  @d<a, direct distance), Enter repeats; object snaps (end, mid, center, quadrant, intersection, insertion) with markers, ortho (F8), grid snap (F9), grid display (F7), osnap (F3); crosshair and pickbox; the object a click would select lights up (a bright line over a blue glow); window (click, click: left to right) and crossing (right to left) selection, and AutoCAD's lasso (press and drag: dragged right a window lasso, left a crossing lasso), with what the window or lasso would select lit up as it moves; Shift+click to remove; the cursor's square fills in over an object a click would select, and over a selected object a four-way arrow shows: press and drag moves the selection (snap grid and Ortho apply), Ctrl when letting go drops a copy instead (a + shows); over a grip the square jumps onto it; polar tracking (F10: every multiple of a set angle, 45 to start, plus extra angles, chosen in Drafting settings; a tracking line and a distance < angle tip; typed distances follow it; Ortho and Polar exclude each other); a short crosshair as AutoCAD's (arms 5% of the view, its CURSORSIZE), with Crosshair size and Full-screen crosshair in Drafting settings; drafting settings kept between sessions; grips to stretch; Trim in quick mode; clipboard between projects (handed over to the system as plain text when the app closes: Qt for Python crashes at exit while the clipboard holds data made in Python); layers (color, on/off, lock, current layer, move selection to a layer); undo/redo of everything through before/after records (model.Edit). Files: .kzcad projects (JSON, saved atomically), DXF import (inches or millimeters; blocks and dimensions exploded) and export (AutoCAD 2013, one sheet per file, frame on layer BORDER), PDF export (vector, real page sizes). Look shared with KanzonasPDF: menus, the ribbon (Home, Sheets, Output, View), light/dark theme, Material Design icons. Spatial index per sheet and chunked path cache: a 60,000-line sheet opens and draws in about 0.6 s. Self-test and unit tests; Windows and Linux builds. |
