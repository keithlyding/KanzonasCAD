# Logos for the website

Made by `tools/make_logos.py --web` (both apps' logos, from the same fonts):

| File | Use |
| --- | --- |
| `kanzonascad-logo.png`, `kanzonaspdf-logo.png` | 936 x 325, on the logos' off-white |
| `...@2x.png` | 1872 x 650, sharp on high-density screens (show at 936 x 325) |
| `...-transparent.png`, `...-transparent@2x.png` | no background, for light backgrounds (the letters are near black; the page behind the cactus is see-through) |

The lettering is drawn at full resolution; the cactus and sunflower are the owner's artwork,
enlarged for the 2x files (a little softer than the letters there).
